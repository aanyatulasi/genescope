# GeneScope

An AI-powered, educational gene explorer built with Next.js, React, Tailwind
CSS, and the OpenAI SDK pointed at OpenRouter. Type a human gene symbol —
like `BRCA1`, `TP53`, `CFTR`, `HBB`, `APOE`, or `FMR1` — and Claude (via
OpenRouter) returns a structured, student-friendly explanation covering
function, associated conditions, inheritance, biotech relevance, and
research prompts.

> **Educational only.** GeneScope is a learning tool. It does not provide
> medical advice, diagnosis, or treatment recommendations.

---

## Features

- 🧬 Structured gene explanations with 10 fields, generated by `anthropic/claude-3.5-sonnet` via OpenRouter
- ⚡ JSON-mode output (`response_format: json_object`) for reliable parsing
- 🔁 Easy to swap models — change a single string to route to any model OpenRouter supports
- 🎨 Biotech-themed UI: glassmorphism cards, soft gradients, responsive layout
- ⚛️ Next.js 15 App Router + React 19 + TypeScript + Tailwind CSS

## Getting started

### 1. Prerequisites

- Node.js 18.18+ (Node 20+ recommended)
- An OpenRouter API key from <https://openrouter.ai/keys>

### 2. Install dependencies

```bash
cd genescope
npm install
```

### 3. Configure your API key

Copy the env template and paste your key:

```bash
cp .env.example .env.local
```

Then edit `.env.local`:

```
OPENROUTER_API_KEY=sk-or-...
```

> `.env.local` is git-ignored by default. Never commit real keys.

### 4. Run the dev server

```bash
npm run dev
```

Open <http://localhost:3000> in your browser. Click one of the example pills
or type a gene symbol and hit **Analyze gene**.

### 5. Build for production

```bash
npm run build
npm run start
```

## How it works

`app/api/analyze-gene/route.ts` is a server-only Next.js route handler. When
the client posts `{ gene: "BRCA1" }`:

1. It validates the input (non-empty, ≤ 32 chars).
2. It calls OpenRouter via the OpenAI SDK (`baseURL:
   https://openrouter.ai/api/v1`) with model `anthropic/claude-3.5-sonnet`,
   an educational system prompt that includes the JSON shape, and
   `response_format: { type: "json_object" }` to guarantee parseable output.
3. The model returns a single JSON object. The route parses it and
   forwards `{ data }` to the browser.
4. The page renders the structured response into themed cards.

To swap models, change the `MODEL` constant at the top of the route — any
model OpenRouter supports works (`openai/gpt-4o-mini`, `google/gemini-pro-1.5`,
`meta-llama/llama-3.1-70b-instruct`, etc.).

## Deploying

### Vercel (recommended)

1. Push the project to GitHub (instructions below).
2. Import the repo at <https://vercel.com/new>.
3. Add `OPENROUTER_API_KEY` as a Vercel environment variable.
4. Deploy.

### Self-hosted

Any Node host works. Set the env var, run `npm run build`, then
`npm run start` behind your reverse proxy of choice.

## Push to GitHub

From inside `genescope/`:

```bash
# 1. Initialise the repo
git init
git add .
git commit -m "Initial commit: GeneScope"

# 2. Create an empty repo on GitHub (via the website or `gh repo create`).
#    Replace YOUR_USERNAME and REPO_NAME below.

# 3. Wire up the remote and push
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/REPO_NAME.git
git push -u origin main
```

If you have the GitHub CLI installed, you can do steps 2 and 3 in one go:

```bash
gh repo create genescope --public --source=. --remote=origin --push
```

> Double-check that `.env.local` is **not** staged before pushing. The
> default Next.js `.gitignore` excludes it, but verify with `git status`.

## Customising

- **Add more example genes** — edit `EXAMPLE_GENES` in `app/page.tsx`.
- **Adjust tone or depth** — tweak `SYSTEM_PROMPT` in
  `app/api/analyze-gene/route.ts`.
- **Add new fields** — extend the JSON shape in `SYSTEM_PROMPT` in the
  API route and the `GeneAnalysis` type plus `Results` component in
  `app/page.tsx`.
- **Try a different model** — change the `MODEL` constant in the API
  route to any [model OpenRouter supports](https://openrouter.ai/models).
- **Theme it** — colours and gradients live in `tailwind.config.ts` and
  `app/globals.css`.
